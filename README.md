# 校内赛哨兵机器人导航

本仓库保存三个导航方案的代码快照，供版本管理、调试记录和校内赛开发使用。

| 目录 | 内容 |
| --- | --- |
| `measurement_only/` | 测量与配置路线方案及配套通信、仿真工具 |
| `full_autonomous/` | 自主感知障碍杆方案及配套工具 |
| `mapping/` | 赛前遥控建图、赛时加载地图定位并执行八字绕桩的方案 |

预建图方案的部署、依赖与验收步骤见 [mapping/README.md](mapping/README.md)。各目录是不同实现，不能混用配置、启动入口或测试结果。

## 当前状态与安全边界

- 这是调试中的软件代码，不是已经完成实车比赛验收的成品。
- 仿真结果和桌面测试不能证明真实串口控制、定位、避障或停车已经通过。
- 现场需确认控制模式、通信接口、坐标系、雷达外参、整车外廓及速度标定。
- 协议控制量不是直接以 m/s 表示的车速，不能盲目提高数值。
- 下位机无指令超时保护时，USB 断开或上位机掉电可能导致最后指令保持；软件零速重试不能代替独立硬件急停。
- 不得通过取消安全检查或将未验收的确认项直接改为 true 来启动实车。

## 上传范围

保留源码、配置、文档、已有仿真结果以及离线依赖 wheel；排除 Python 缓存、本地展开依赖、运行日志、ROS 录包和构建目录。忽略上传不会删除本地文件。

本次上传以桌面文件夹的现有内容为准，不会自动合并其他目录或其他 agent 的修改。第三方依赖、模型及规则资料的权利仍归原作者；未额外指定开源许可证。
